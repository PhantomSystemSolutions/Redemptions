| Command | Description |
|----------|----------|
| fshop | Responds with the Error Message: "No Item Provided." Also, if enabled, sends a link to Shop Commands Page. |
| fshop {Item Name} {Quantity} | If {Quantity} of {Item Name} is available, purchases the Item. Each Item has it's own Limits to purchasing. [Shop Inventory Page](https://github.com/PhantomSystemSolutions/Redemptions/blob/main/%5BUnused%5D%20Shop%20Inventory.md)|
| fshop info {Item Name} | Gives a short description of the given Shop Item. |
| fshop list | Lists available shop inventory. Also sends link to Shop Inventory Page. |
| fshop owed | Sends your Prizes Owed. |
| fshop reset | Broadcaster-only Command. This will reset all Shop Item that have had purchases made. |
